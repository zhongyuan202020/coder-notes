## 定义
![](https://raw.githubusercontent.com/zhongyuan202020/coder-notes-image/main/public/data-structrue/trie/trie.png)

字典树（Trie树，又称前缀树）是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补全和拼写检查。

字典树的基本思想是利用字符串的公共前缀来降低查询时间，最大限度地减少无谓的字符串比较。

关键词：
- 前缀共享：相同前缀的字符串共享存储空间
- 路径表示：从根到节点的路径表示一个字符串
- 边表示字符：树的边通常表示字符，节点则表示字符串

## 特点
1. 利用字符串的公共前缀来减少存储和查询时间
2. 查询效率与字符串长度相关，而非数据量大小
3. 空间换时间的典型应用，适合需要快速检索前缀的场景
4. 插入和查询操作的时间复杂度为O(m)，其中m是键长

## 实现原理
字典树的实现原理基于多叉树结构，每个节点包含多个子节点，对应不同的字符。

一个标准的字典树节点通常包含以下部分：
1. 子节点数组或映射：存储当前节点的所有子节点
2. 终止标志：标记当前节点是否是某个单词的结尾

字典树的基本操作包括：
- 插入：将一个单词添加到字典树中
- 查找：检查一个单词是否在字典树中
- 前缀匹配：查找具有特定前缀的所有单词
- 删除：从字典树中移除一个单词

## 时间复杂度
<!-- 使用表格的形式展示 -->
| 操作 | 时间复杂度 |
| --- | --- |
| 查找 | O(m) |
| 插入 | O(m) |
| 删除 | O(m) |
| 前缀匹配 | O(m + k) |

其中，m是键的长度，k是匹配前缀的单词数量。

## 知识扩展
### 字典树的优缺点
优点：
1. 查询效率高，与字符串长度相关而非数据量
2. 前缀匹配功能强大，适合自动补全等应用
4. 按字典序遍历方便

缺点：
1. 空间消耗较大，尤其是当字符集较大时
2. 如果数据稀疏，会有很多空链接，造成空间浪费
3. 不适合精确匹配和模糊匹配
4. 构建成本较高

### 字典树与其他数据结构的比较
1. 与哈希表比较：
   - 哈希表查询时间复杂度为O(1)，但不支持前缀匹配
   - 字典树支持前缀匹配，但空间消耗更大
   - 哈希表不保持键的顺序，字典树可以按字典序遍历

2. 与平衡树比较：
   - 平衡树如红黑树查询时间为O(log n)，n为键数量
   - 字典树查询时间为O(m)，m为键长度，通常m远小于log n
   - 平衡树支持范围查询，字典树更适合前缀匹配

### 应用场景
1. 自动补全和拼写检查
2. 搜索引擎的关键词提示
3. IP路由表查找
4. 字符串检索，如文本编辑器的查找功能
5. 单词游戏中的单词验证
6. 电话号码簿的快速查找

## 功能实现
以 Java 为例，实现字典树的基本操作。
```java
public class Trie {
    private class TrieNode {
        // 子节点映射，键为字符，值为对应的子节点
        private Map<Character, TrieNode> children;
        // 标记当前节点是否为某个单词的结尾
        private boolean isEndOfWord;
        
        public TrieNode() {
            children = new HashMap<>();
            isEndOfWord = false;
        }
    }
    
    private TrieNode root;
    
    public Trie() {
        root = new TrieNode();
    }
    
    // 插入单词
    public void insert(String word) {
        TrieNode current = root;
        
        for (char c : word.toCharArray()) {
            TrieNode node = current.children.get(c);
            if (node == null) {
                node = new TrieNode();
                current.children.put(c, node);
            }
            current = node;
        }
        
        // 标记单词结束
        current.isEndOfWord = true;
    }
    
    // 查找单词
    public boolean search(String word) {
        TrieNode node = searchPrefix(word);
        return node != null && node.isEndOfWord;
    }
    
    // 查找前缀
    public boolean startsWith(String prefix) {
        return searchPrefix(prefix) != null;
    }
    
    // 辅助方法：查找前缀对应的节点
    private TrieNode searchPrefix(String prefix) {
        TrieNode current = root;
        
        for (char c : prefix.toCharArray()) {
            TrieNode node = current.children.get(c);
            if (node == null) {
                return null;
            }
            current = node;
        }
        
        return current;
    }
    
    // 删除单词
    public void delete(String word) {
        delete(root, word, 0);
    }
    
    private boolean delete(TrieNode current, String word, int index) {
        if (index == word.length()) {
            // 如果不是单词结尾，无法删除
            if (!current.isEndOfWord) {
                return false;
            }
            current.isEndOfWord = false;
            // 如果当前节点没有子节点，可以删除
            return current.children.isEmpty();
        }
        
        char c = word.charAt(index);
        TrieNode node = current.children.get(c);
        if (node == null) {
            return false;
        }
        
        boolean shouldDeleteCurrentNode = delete(node, word, index + 1);
        
        // 如果子节点应该被删除
        if (shouldDeleteCurrentNode) {
            current.children.remove(c);
            // 当前节点是否可以被删除
            return current.children.isEmpty() && !current.isEndOfWord;
        }
        
        return false;
    }
    
    // 获取所有以给定前缀开始的单词
    public List<String> getWordsWithPrefix(String prefix) {
        List<String> result = new ArrayList<>();
        TrieNode prefixNode = searchPrefix(prefix);
        
        if (prefixNode != null) {
            collectWords(prefixNode, prefix, result);
        }
        
        return result;
    }
    
    private void collectWords(TrieNode node, String prefix, List<String> result) {
        if (node.isEndOfWord) {
            result.add(prefix);
        }
        
        for (Map.Entry<Character, TrieNode> entry : node.children.entrySet()) {
            collectWords(entry.getValue(), prefix + entry.getKey(), result);
        }
    }
}
```
