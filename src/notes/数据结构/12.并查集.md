## 定义
![](https://raw.githubusercontent.com/zhongyuan202020/coder-notes-image/main/public/data-structrue/union-find/union-find.png)

并查集（Union-Find，也称为不相交集合或Disjoint-Set）是一种用于管理元素所属集合的数据结构。它主要支持两种操作：合并（Union）两个集合和查找（Find）元素所属的集合。

并查集的基本思想是使用树形结构表示集合，每个集合是一棵树，树的根节点代表集合的代表元素。

关键词：
- 集合表示：使用树形结构表示集合，树根为集合代表
- 路径压缩：优化查找操作，减少树的高度
- 按秩合并：优化合并操作，保持树的平衡

## 特点
1. 高效地处理不相交集合的合并和查找操作
2. 适合处理元素的动态连通性问题
3. 实现简单，空间复杂度低
4. 通过路径压缩和按秩合并优化，接近常数时间复杂度

## 实现原理
并查集的实现原理基于树形结构，每个元素都是树中的一个节点，初始时每个元素构成一个单独的集合（即一棵只有一个节点的树）。

并查集的基本操作包括：
- 查找（Find）：确定元素属于哪个集合，即找到元素所在树的根节点
- 合并（Union）：将两个集合合并为一个集合，即将一棵树的根连接到另一棵树的根

为了提高效率，并查集通常采用以下优化技术：
1. 路径压缩：在查找操作中，将查找路径上的所有节点直接连接到根节点，减少树的高度
2. 按秩合并：在合并操作中，将较小的树连接到较大的树上，避免树变得过高

## 时间复杂度
<!-- 使用表格的形式展示 -->
| 操作 | 时间复杂度 |
| --- | --- |
| 查找（无优化） | O(n) |
| 查找（路径压缩） | 接近 O(1) |
| 合并（无优化） | O(n) |
| 合并（按秩合并+路径压缩） | 接近 O(1) |

其中，n是元素的数量。使用路径压缩和按秩合并优化后，操作的平均时间复杂度接近常数级别，理论上为O(α(n))，其中α(n)是阿克曼函数的反函数，最多为4或者5，在实际应用中可以视为常数。

## 知识扩展
### 并查集的优缺点
优点：
1. 实现简单，易于理解
2. 空间复杂度低，仅需要一个数组
3. 操作效率高，优化后接近常数时间复杂度
4. 适合处理大规模的动态连通性问题

缺点：
1. 不支持集合的分割操作
2. 不能直接获取集合的所有元素
3. 不支持删除元素操作
4. 在某些特殊情况下，性能可能退化

### 并查集与其他数据结构的比较
1. 与图算法比较：
   - 并查集在处理动态连通性问题上比传统图算法更高效

2. 与树结构比较：
   - 并查集是一种特殊的树结构，专注于集合操作
   - 普通树结构支持更多操作，如插入、删除、遍历等
   - 并查集通过特殊的优化技术（路径压缩、按秩合并）实现高效操作

### 应用场景
1. 网络连接问题：判断网络中的节点是否连通
2. 最小生成树算法（Kruskal算法）
3. 图像处理中的连通区域标记
4. 社交网络中的朋友圈分析
5. 等价类问题：判断元素是否属于同一等价类
6. 动态连通性问题：判断两个元素是否连通

## 功能实现
以 Java 为例，实现并查集的基本操作。
```java
public class UnionFind {
    private int[] parent; // 存储每个元素的父节点
    private int[] rank;   // 存储每个根节点对应树的高度（秩）
    private int count;    // 集合数量
    
    // 初始化并查集，每个元素构成一个单独的集合
    public UnionFind(int n) {
        parent = new int[n];
        rank = new int[n];
        count = n;
        
        // 初始化，每个元素的父节点是自己
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            rank[i] = 1; // 初始秩为1
        }
    }
    
    // 查找元素所属的集合（即根节点）
    public int find(int x) {
        // 路径压缩：将x到根节点路径上的所有节点直接连接到根节点
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    // 合并两个元素所属的集合
    public void union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        
        // 如果已经在同一集合中，不需要合并
        if (rootX == rootY) {
            return;
        }
        
        // 按秩合并：将较小的树连接到较大的树上
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            // 如果秩相同，将rootY连接到rootX，并增加rootX的秩
            parent[rootY] = rootX;
            rank[rootX]++;
        }
        
        // 集合数量减1
        count--;
    }
    
    // 判断两个元素是否在同一集合中
    public boolean isConnected(int x, int y) {
        return find(x) == find(y);
    }
    
    // 获取集合数量
    public int getCount() {
        return count;
    }
    
    // 获取集合的大小（即集合中元素的数量）
    public int getSize(int x) {
        int root = find(x);
        int size = 0;
        
        for (int i = 0; i < parent.length; i++) {
            if (find(i) == root) {
                size++;
            }
        }
        
        return size;
    }
}
```
