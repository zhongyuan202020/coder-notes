## 定义
![](https://raw.githubusercontent.com/zhongyuan202020/coder-notes-image/main/public/data-structrue/b-tree/b-tree.png)

B树（B-tree）是一种自平衡的树状数据结构，能够保持数据有序，支持在对数时间内进行查找、顺序访问、插入和删除操作。B树是一个一般化的二叉搜索树，每个节点可以拥有2个以上的子节点。

B树的基本思想是通过增加每个节点的分支数量来减少树的高度，从而减少磁盘I/O操作次数，提高查询效率。

关键词：
- 多路搜索树：每个节点可以有多个子节点
- 平衡结构：所有叶子节点都在同一层级
- 磁盘友好：设计用于减少磁盘I/O操作

## 特点
1. 所有叶子节点都在同一层级，保证了树的平衡性
2. 每个节点最多有m个子节点（m阶B树）
3. 除根节点外，每个非叶子节点至少有⌈m/2⌉个子节点
4. 如果根节点不是叶子节点，则至少有2个子节点
5. 有n个子节点的非叶子节点包含n-1个键值
6. 所有节点中的键值按升序排列
7. 适合大块数据的读写操作，减少磁盘I/O次数

## 实现原理
B树的实现原理基于多路搜索和分裂合并策略，以保持树的平衡。

B树的基本操作包括：
- 查找（Search）：从根节点开始，根据键值大小比较，递归地在子树中查找
- 插入（Insert）：找到合适的叶子节点插入，如果节点已满则分裂
- 删除（Delete）：找到并删除键值，如果删除后节点的键值数量不足最小要求，则进行合并或重新分配

B树的节点结构通常包含：
1. 键值数组：存储有序的键值
2. 子节点指针数组：指向子树的指针
3. 键值数量：当前节点中存储的键值数量

## 时间复杂度
<!-- 使用表格的形式展示 -->
| 操作 | 时间复杂度 |
| --- | --- |
| 查找 | O(log n) |
| 插入 | O(log n) |
| 删除 | O(log n) |
| 遍历 | O(n) |

其中，n是树中节点的数量。B树的所有主要操作都具有对数级的时间复杂度，这使得它在处理大规模数据时非常高效，特别是当数据存储在外部存储设备（如磁盘）上时。

## 知识扩展
### B树的优缺点
优点：
1. 减少磁盘I/O操作次数，提高查询效率
2. 适合大数据量的存储和检索
3. 自平衡特性，无需额外的平衡操作
4. 支持范围查询

缺点：
1. 实现复杂度高
2. 相比于某些特定场景的数据结构，可能不是最优选择
3. 在内存中使用时，可能不如其他数据结构高效
4. 删除操作较为复杂

### B树与其他数据结构的比较
1. 与二叉搜索树比较：
   - B树每个节点可以有多个子节点，减少了树的高度
   - B树更适合磁盘存储，二叉搜索树更适合内存存储
   - B树自平衡，而普通二叉搜索树可能退化为链表

2. 与B+树比较：
   - B树在内部节点和叶子节点都存储数据
   - B+树只在叶子节点存储数据，内部节点只存储键值
   - B+树的叶子节点通过链表相连，更适合范围查询
   - B+树通常用于数据库索引，B树用于文件系统

3. 与红黑树比较：
   - B树更适合磁盘存储，红黑树更适合内存存储
   - B树的高度通常比红黑树小，I/O操作更少
   - 红黑树实现相对简单，但在外存环境下效率较低

### 应用场景
1. 文件系统：如NTFS、ext4等文件系统使用B树或其变种
2. 数据库索引：如MySQL的InnoDB存储引擎使用B+树
3. 键值存储系统：如Berkeley DB使用B树
4. 搜索引擎：用于存储和检索索引
5. 缓存系统：用于高效地组织和检索缓存数据

## 功能实现
以 Java 为例，实现B树的基本操作。
```java
public class BTree<K extends Comparable<K>, V> {
    private static final int DEFAULT_ORDER = 4; // 默认为4阶B树
    
    private Node root;
    private final int order; // B树的阶数
    private int size;
    
    // B树节点类
    private class Node {
        private int keyCount; // 当前节点中键值对的数量
        private Entry[] entries; // 键值对数组
        private Node[] children; // 子节点数组
        private boolean leaf; // 是否为叶子节点
        
        // 节点构造函数
        public Node(boolean leaf) {
            this.leaf = leaf;
            this.entries = new Entry[order - 1]; // 最多存储order-1个键值对
            this.children = leaf ? null : new Node[order]; // 最多有order个子节点
            this.keyCount = 0;
        }
    }
    
    // 键值对类
    private class Entry {
        private K key;
        private V value;
        
        public Entry(K key, V value) {
            this.key = key;
            this.value = value;
        }
    }
    
    // 构造函数
    public BTree() {
        this(DEFAULT_ORDER);
    }
    
    public BTree(int order) {
        if (order < 3) {
            throw new IllegalArgumentException("B树的阶数必须大于等于3");
        }
        this.order = order;
        this.root = new Node(true); // 初始化根节点为叶子节点
        this.size = 0;
    }
    
    // 查找操作
    public V search(K key) {
        if (key == null) {
            throw new IllegalArgumentException("键不能为空");
        }
        return search(root, key);
    }
    
    private V search(Node node, K key) {
        int i = 0;
        // 在当前节点中查找第一个大于等于key的位置
        while (i < node.keyCount && key.compareTo(node.entries[i].key) > 0) {
            i++;
        }
        
        // 如果找到了匹配的键
        if (i < node.keyCount && key.compareTo(node.entries[i].key) == 0) {
            return node.entries[i].value;
        }
        
        // 如果是叶子节点且未找到，则返回null
        if (node.leaf) {
            return null;
        }
        
        // 递归在子节点中查找
        return search(node.children[i], key);
    }
    
    // 插入操作
    public void insert(K key, V value) {
        if (key == null) {
            throw new IllegalArgumentException("键不能为空");
        }
        
        // 如果根节点已满，需要分裂
        if (root.keyCount == order - 1) {
            Node newRoot = new Node(false);
            newRoot.children[0] = root;
            splitChild(newRoot, 0);
            root = newRoot;
        }
        
        insertNonFull(root, key, value);
        size++;
    }
    
    // 在非满节点中插入键值对
    private void insertNonFull(Node node, K key, V value) {
        int i = node.keyCount - 1;
        
        // 如果是叶子节点，直接插入
        if (node.leaf) {
            // 找到合适的插入位置
            while (i >= 0 && key.compareTo(node.entries[i].key) < 0) {
                node.entries[i + 1] = node.entries[i];
                i--;
            }
            
            // 插入新键值对
            node.entries[i + 1] = new Entry(key, value);
            node.keyCount++;
        } else {
            // 如果是内部节点，找到合适的子节点
            while (i >= 0 && key.compareTo(node.entries[i].key) < 0) {
                i--;
            }
            i++;
            
            // 如果子节点已满，需要先分裂
            if (node.children[i].keyCount == order - 1) {
                splitChild(node, i);
                if (key.compareTo(node.entries[i].key) > 0) {
                    i++;
                }
            }
            
            // 递归在子节点中插入
            insertNonFull(node.children[i], key, value);
        }
    }
    
    // 分裂子节点
    private void splitChild(Node parent, int index) {
        Node child = parent.children[index];
        Node newChild = new Node(child.leaf);
        
        // 分配键值对和子节点
        newChild.keyCount = order / 2 - 1;
        for (int j = 0; j < newChild.keyCount; j++) {
            newChild.entries[j] = child.entries[j + order / 2];
        }
        
        // 如果不是叶子节点，还需要分配子节点
        if (!child.leaf) {
            for (int j = 0; j < order / 2; j++) {
                newChild.children[j] = child.children[j + order / 2];
            }
        }
        
        // 更新原子节点的键值对数量
        child.keyCount = order / 2 - 1;
        
        // 在父节点中插入中间键值对
        for (int j = parent.keyCount; j > index; j--) {
            parent.children[j + 1] = parent.children[j];
        }
        parent.children[index + 1] = newChild;
        
        for (int j = parent.keyCount - 1; j >= index; j--) {
            parent.entries[j + 1] = parent.entries[j];
        }
        parent.entries[index] = child.entries[order / 2 - 1];
        parent.keyCount++;
    }
    
    // 获取B树大小
    public int size() {
        return size;
    }
    
    // 判断B树是否为空
    public boolean isEmpty() {
        return size == 0;
    }
}
```
