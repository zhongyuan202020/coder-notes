## 定义
![](https://raw.githubusercontent.com/zhongyuan202020/coder-notes-image/main/public/data-structrue/segment-tree/segment-tree.png)

线段树（Segment Tree）是一种二叉树形数据结构，用于存储区间或线段的信息，并支持高效的区间查询和更新操作。每个节点代表一个区间，父节点的区间是子节点区间的并集。

线段树的基本思想是通过分治策略，将区间划分为多个子区间，并在树的节点中存储这些区间的聚合信息（如区间和、最大值、最小值等）。

关键词：
- 区间表示：每个节点代表一个区间
- 分治思想：将大区间分解为小区间
- 聚合信息：存储区间的统计信息

## 特点
1. 高效处理区间查询和更新操作
2. 适合解决区间统计问题
3. 空间复杂度为O(n)，其中n是原始数组的长度
4. 支持多种区间操作（求和、最大值、最小值等）
5. 可以处理动态变化的数据

## 实现原理
线段树的实现原理基于分治策略，将区间[l, r]分为左右两个子区间[l, mid]和[mid+1, r]，其中mid = (l + r) / 2。

线段树的基本操作包括：
- 构建（Build）：自底向上构建线段树，计算每个节点的聚合信息
- 查询（Query）：在线段树中查找指定区间的聚合信息
- 更新（Update）：修改原始数组中的某个元素，并更新线段树中相应的节点

线段树通常使用数组实现，对于区间[0, n-1]的线段树：
1. 根节点索引为1（或0，取决于实现）
2. 对于索引为i的节点，其左子节点索引为2*i，右子节点索引为2*i+1
3. 父节点的值是子节点值的聚合（如求和、取最大值等）

## 时间复杂度
<!-- 使用表格的形式展示 -->
| 操作 | 时间复杂度 |
| --- | --- |
| 构建 | O(n) |
| 查询 | O(log n) |
| 更新（单点） | O(log n) |
| 更新（区间） | O(log n) 到 O(n log n)，取决于实现方式 |

其中，n是原始数组的长度。线段树的查询和更新操作都具有对数级的时间复杂度，这使得它在处理大规模数据的区间操作时非常高效。

## 知识扩展
### 线段树的优缺点
优点：
1. 高效的区间查询和更新操作
2. 适应性强，可以解决多种区间问题
3. 可以处理动态变化的数据
4. 实现相对简单，易于理解

缺点：
1. 空间开销较大，通常需要4n的空间
2. 对于某些特定问题，可能存在更专门的数据结构（如树状数组）
3. 实现懒惰传播（lazy propagation）增加了复杂性
4. 不适合处理非区间聚合类的问题

### 线段树与其他数据结构的比较
1. 与树状数组（Binary Indexed Tree）比较：
   - 线段树支持更多种类的区间操作
   - 树状数组实现更简单，空间效率更高
   - 线段树可以处理任意区间查询，树状数组主要处理前缀和查询

2. 与平衡树比较：
   - 线段树专注于区间操作
   - 平衡树更适合动态插入和删除元素
   - 线段树在区间查询上通常更高效

3. 与稀疏表（Sparse Table）比较：
   - 线段树支持单点更新
   - 稀疏表不支持更新操作，但区间查询更快（O(1)）
   - 线段树空间复杂度更低（O(n) vs O(n log n)）

### 应用场景
1. 区间求和、最大值、最小值查询
2. 区间修改操作（如区间加减、区间赋值）
3. 计算几何中的线段相交问题
4. 范围最小查询（Range Minimum Query, RMQ）
5. 在线算法竞赛中的区间问题
6. 数据库中的范围查询优化

## 功能实现
以 Java 为例，实现线段树的基本操作（以区间求和为例）。
```java
public class SegmentTree {
    private int[] tree;    // 存储线段树节点
    private int[] lazy;   // 用于懒惰传播
    private int[] nums;   // 原始数组
    private int n;        // 原始数组长度
    
    // 初始化线段树
    public SegmentTree(int[] arr) {
        n = arr.length;
        nums = new int[n];
        System.arraycopy(arr, 0, nums, 0, n);
        
        // 线段树数组大小为4n
        tree = new int[4 * n];
        lazy = new int[4 * n];
        
        // 构建线段树
        build(0, 0, n - 1);
    }
    
    // 构建线段树，node为当前节点索引，start和end为当前区间范围
    private void build(int node, int start, int end) {
        if (start == end) {
            // 叶子节点，直接赋值
            tree[node] = nums[start];
            return;
        }
        
        int mid = (start + end) / 2;
        int leftNode = 2 * node + 1;
        int rightNode = 2 * node + 2;
        
        // 递归构建左右子树
        build(leftNode, start, mid);
        build(rightNode, mid + 1, end);
        
        // 当前节点的值为左右子节点值的和
        tree[node] = tree[leftNode] + tree[rightNode];
    }
    
    // 区间查询，查询区间[queryStart, queryEnd]的和
    public int query(int queryStart, int queryEnd) {
        return query(0, 0, n - 1, queryStart, queryEnd);
    }
    
    private int query(int node, int start, int end, int queryStart, int queryEnd) {
        // 处理懒惰标记
        if (lazy[node] != 0) {
            tree[node] += (end - start + 1) * lazy[node];
            
            if (start != end) {
                // 非叶子节点，将懒惰标记传递给子节点
                lazy[2 * node + 1] += lazy[node];
                lazy[2 * node + 2] += lazy[node];
            }
            
            lazy[node] = 0;
        }
        
        // 区间不相交
        if (queryStart > end || queryEnd < start) {
            return 0;
        }
        
        // 当前区间完全包含在查询区间内
        if (queryStart <= start && queryEnd >= end) {
            return tree[node];
        }
        
        // 区间部分重叠，需要分别查询左右子区间
        int mid = (start + end) / 2;
        int leftSum = query(2 * node + 1, start, mid, queryStart, queryEnd);
        int rightSum = query(2 * node + 2, mid + 1, end, queryStart, queryEnd);
        
        return leftSum + rightSum;
    }
    
    // 单点更新，将索引为index的元素更新为value
    public void update(int index, int value) {
        update(0, 0, n - 1, index, value);
    }
    
    private void update(int node, int start, int end, int index, int value) {
        // 处理懒惰标记
        if (lazy[node] != 0) {
            tree[node] += (end - start + 1) * lazy[node];
            
            if (start != end) {
                lazy[2 * node + 1] += lazy[node];
                lazy[2 * node + 2] += lazy[node];
            }
            
            lazy[node] = 0;
        }
        
        // 不在范围内
        if (index < start || index > end) {
            return;
        }
        
        // 找到目标叶子节点
        if (start == end) {
            tree[node] = value;
            nums[index] = value;
            return;
        }
        
        int mid = (start + end) / 2;
        if (index <= mid) {
            update(2 * node + 1, start, mid, index, value);
        } else {
            update(2 * node + 2, mid + 1, end, index, value);
        }
        
        // 更新当前节点的值
        tree[node] = tree[2 * node + 1] + tree[2 * node + 2];
    }
    
    // 区间更新，将区间[updateStart, updateEnd]中的每个元素都增加value
    public void updateRange(int updateStart, int updateEnd, int value) {
        updateRange(0, 0, n - 1, updateStart, updateEnd, value);
    }
    
    private void updateRange(int node, int start, int end, int updateStart, int updateEnd, int value) {
        // 处理懒惰标记
        if (lazy[node] != 0) {
            tree[node] += (end - start + 1) * lazy[node];
            
            if (start != end) {
                lazy[2 * node + 1] += lazy[node];
                lazy[2 * node + 2] += lazy[node];
            }
            
            lazy[node] = 0;
        }
        
        // 区间不相交
        if (updateStart > end || updateEnd < start) {
            return;
        }
        
        // 当前区间完全包含在更新区间内
        if (updateStart <= start && updateEnd >= end) {
            tree[node] += (end - start + 1) * value;
            
            if (start != end) {
                lazy[2 * node + 1] += value;
                lazy[2 * node + 2] += value;
            }
            
            return;
        }
        
        // 区间部分重叠，需要分别更新左右子区间
        int mid = (start + end) / 2;
        updateRange(2 * node + 1, start, mid, updateStart, updateEnd, value);
        updateRange(2 * node + 2, mid + 1, end, updateStart, updateEnd, value);
        
        // 更新当前节点的值
        tree[node] = tree[2 * node + 1] + tree[2 * node + 2];
    }
    
    // 获取原始数组
    public int[] getArray() {
        return nums;
    }
}
```
