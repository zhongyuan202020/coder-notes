## 定义
![](https://raw.githubusercontent.com/zhongyuan202020/coder-notes-image/main/public/data-structrue/skiplist/skiplist.png)

有序链表在查找时需要从头遍历，时间复杂度为O(n)。为了优化这一过程，跳表应运而生。

跳表是一种随机化的数据结构，基于有序链表，通过维护多层索引来加速查找过程。它可以看作是对有序链表的优化，使其在性能上接近平衡树，但实现更为简单。

关键词：
- 多层索引：通过概率随机建立多层索引
- 随机化：节点层数通过随机函数决定
- 快速查找：利用索引层跳跃查找，减少比较次数

## 特点
1. 期望时间复杂度为O(log n)，但最坏情况下可能退化为O(n)
2. 空间复杂度为O(n)，额外使用的空间主要用于存储索引
3. 实现简单，相比平衡树更易于理解和维护
4. 具有良好的随机访问性能
5. 支持快速的插入和删除操作

## 工作原理
跳表的核心原理是通过建立多层索引，实现快速跳跃式查找。

每个节点按照一定概率（通常为1/2）决定是否向上提升一层。这样，顶层索引覆盖的节点最少，底层包含所有节点。

查找时，从顶层索引开始，水平方向找到不大于目标值的最大节点，然后下降到下一层继续查找，直到最底层找到精确位置。

插入和删除操作也遵循类似的查找路径，然后进行相应的节点操作和索引调整。

## 知识扩展
### 跳表的优缺点
优点：
1. 实现简单，比平衡树更容易理解和维护
2. 插入和删除操作不需要复杂的平衡调整
3. 支持高效的范围查询
4. 内存占用相对平衡树更小
5. 可以灵活调整索引层数，平衡性能和空间需求

缺点：
1. 性能依赖于随机函数的质量
2. 最坏情况下可能退化为O(n)的时间复杂度
3. 需要额外的空间存储索引
4. 不如某些平衡树（如红黑树）的性能稳定

### 跳表与其他数据结构的比较
1. 与平衡二叉树（如AVL树、红黑树）比较：
   - 跳表实现更简单，不需要复杂的旋转操作
   - 平衡树提供稳定的最坏情况性能保证
   - 跳表在范围查询上表现更好

2. 与哈希表比较：
   - 跳表保持元素有序，支持范围查询
   - 哈希表提供O(1)的查找性能，但不保持元素有序
   - 跳表更适合需要有序性的场景

3. 与B树比较：
   - B树更适合磁盘存储和大规模数据
   - 跳表更适合内存数据结构
   - 两者都支持范围查询

### 应用场景
1. Redis中的有序集合(Sorted Set)的底层实现
2. 需要快速查找和范围查询的场景
3. 内存数据库的索引结构
4. 需要简单实现但性能接近平衡树的场景
5. 实时性要求高的系统

## 功能实现
以 Java 为例，实现跳表的基本操作。
```java
public class SkipList<T extends Comparable<T>> {

    // 最大层数
    private static final int MAX_LEVEL = 16;
    // 随机层数概率，通常为0.5
    private static final double P = 0.5;
    // 当前跳表的层数
    private int level;
    // 头节点
    private Node<T> head;
    // 元素数量
    private int size;
    
    // 节点定义
    private static class Node<T extends Comparable<T>> {
        T value;
        // 每层的下一个节点
        Node<T>[] next;
        
        @SuppressWarnings("unchecked")
        public Node(T value, int level) {
            this.value = value;
            this.next = new Node[level];
        }
    }
    
    @SuppressWarnings("unchecked")
    public SkipList() {
        this.level = 1;
        this.head = new Node<>(null, MAX_LEVEL);
        this.size = 0;
    }
    
    // 随机生成层数
    private int randomLevel() {
        int level = 1;
        while (Math.random() < P && level < MAX_LEVEL) {
            level++;
        }
        return level;
    }
    
    // 查找元素
    public boolean contains(T value) {
        Node<T> current = head;
        // 从最高层开始查找
        for (int i = level - 1; i >= 0; i--) {
            // 在当前层找到小于目标值的最大节点
            while (current.next[i] != null && current.next[i].value.compareTo(value) < 0) {
                current = current.next[i];
            }
        }
        // 移动到下一个节点，检查是否为目标值
        current = current.next[0];
        return current != null && current.value.compareTo(value) == 0;
    }
    
    // 插入元素
    public void insert(T value) {
        Node<T> current = head;
        // 用于记录每层需要更新的节点
        @SuppressWarnings("unchecked")
        Node<T>[] update = new Node[MAX_LEVEL];
        
        // 从最高层开始查找插入位置
        for (int i = level - 1; i >= 0; i--) {
            while (current.next[i] != null && current.next[i].value.compareTo(value) < 0) {
                current = current.next[i];
            }
            update[i] = current;
        }
        
        // 移动到第0层的下一个节点
        current = current.next[0];
        
        // 如果当前节点不存在或者值不等于要插入的值，则插入新节点
        if (current == null || current.value.compareTo(value) != 0) {
            int newLevel = randomLevel();
            
            // 如果新节点的层数大于当前跳表的层数，更新跳表层数和update数组
            if (newLevel > level) {
                for (int i = level; i < newLevel; i++) {
                    update[i] = head;
                }
                level = newLevel;
            }
            
            // 创建新节点
            Node<T> newNode = new Node<>(value, newLevel);
            
            // 更新每层的指针
            for (int i = 0; i < newLevel; i++) {
                newNode.next[i] = update[i].next[i];
                update[i].next[i] = newNode;
            }
            
            size++;
        }
    }
    
    // 删除元素
    public boolean delete(T value) {
        Node<T> current = head;
        @SuppressWarnings("unchecked")
        Node<T>[] update = new Node[MAX_LEVEL];
        
        // 从最高层开始查找删除位置
        for (int i = level - 1; i >= 0; i--) {
            while (current.next[i] != null && current.next[i].value.compareTo(value) < 0) {
                current = current.next[i];
            }
            update[i] = current;
        }
        
        current = current.next[0];
        
        // 如果找到了要删除的节点
        if (current != null && current.value.compareTo(value) == 0) {
            // 更新每层的指针，跳过要删除的节点
            for (int i = 0; i < level; i++) {
                if (update[i].next[i] != current) {
                    break;
                }
                update[i].next[i] = current.next[i];
            }
            
            // 如果删除节点后，最高层没有节点了，则降低层数
            while (level > 1 && head.next[level - 1] == null) {
                level--;
            }
            
            size--;
            return true;
        }
        return false;
    }
    
    // 获取元素数量
    public int size() {
        return size;
    }
    
    // 判断跳表是否为空
    public boolean isEmpty() {
        return size == 0;
    }
}
```
