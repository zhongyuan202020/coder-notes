## 定义
![](https://raw.githubusercontent.com/zhongyuan202020/coder-notes-image/main/public/data-structrue/b+tree/b+tree.png)

B+树是B树的一种变体，也是一种自平衡的树状数据结构，广泛应用于数据库和文件系统中。B+树的特点是所有数据都存储在叶子节点，内部节点只存储键值和指向子节点的指针，这种结构使得B+树特别适合于磁盘存储和范围查询。

B+树的基本思想是通过增加每个节点的分支数量来减少树的高度，同时将所有数据存储在叶子节点并通过链表相连，以支持高效的顺序访问和范围查询。

关键词：
- 多路搜索树：每个节点可以有多个子节点
- 叶子节点链表：所有叶子节点通过链表相连
- 数据只存储在叶子节点：内部节点只存储索引信息
- 平衡结构：所有叶子节点都在同一层级

## 特点
1. 所有叶子节点都在同一层级，保证了树的平衡性
2. 每个节点最多有m个子节点（m阶B+树）
3. 除根节点外，每个非叶子节点至少有⌈m/2⌉个子节点
4. 如果根节点不是叶子节点，则至少有2个子节点
5. 所有数据记录都存储在叶子节点中
6. 内部节点只存储键值和指向子节点的指针，不存储数据
7. 叶子节点之间通过指针连接成一个有序链表，便于范围查询
8. 每个叶子节点都包含指向下一个叶子节点的指针
9. 适合大块数据的读写操作和范围查询

## B+树与B树的区别
1. 数据存储位置：
   - B树：数据存储在所有节点中（内部节点和叶子节点）
   - B+树：数据只存储在叶子节点中，内部节点只存储键值

2. 键值重复：
   - B树：每个键值在树中只出现一次
   - B+树：内部节点的键值会在叶子节点中重复出现

3. 叶子节点连接：
   - B树：叶子节点之间没有连接
   - B+树：叶子节点通过指针连接成一个有序链表

4. 查询效率：
   - B树：查询任意键值的效率相当
   - B+树：查询叶子节点的数据更高效，且支持高效的范围查询

5. 树的高度：
   - B+树通常比同样数据量的B树高度更小，因为内部节点不存储数据，可以容纳更多指针

## 实现原理
B+树的实现原理基于多路搜索和分裂合并策略，以保持树的平衡，同时通过叶子节点链表支持高效的顺序访问。

B+树的基本操作包括：
- 查找（Search）：从根节点开始，根据键值大小比较，递归地在子树中查找，直到叶子节点
- 插入（Insert）：找到合适的叶子节点插入，如果节点已满则分裂
- 删除（Delete）：找到并删除叶子节点中的键值，如果删除后节点的键值数量不足最小要求，则进行合并或重新分配

B+树的节点结构通常包含：
1. 内部节点：
   - 键值数组：存储有序的键值
   - 子节点指针数组：指向子树的指针
   - 键值数量：当前节点中存储的键值数量

2. 叶子节点：
   - 键值数组：存储有序的键值
   - 数据指针数组：指向实际数据记录的指针
   - 下一个叶子节点指针：指向下一个叶子节点，形成链表
   - 键值数量：当前节点中存储的键值数量

## 时间复杂度
<!-- 使用表格的形式展示 -->
| 操作 | 时间复杂度 |
| --- | --- |
| 查找 | O(log n) |
| 插入 | O(log n) |
| 删除 | O(log n) |
| 顺序遍历 | O(n) |
| 范围查询 | O(log n + k)，k是结果集大小 |

其中，n是树中节点的数量。B+树的所有主要操作都具有对数级的时间复杂度，这使得它在处理大规模数据时非常高效，特别是当数据存储在外部存储设备（如磁盘）上时。范围查询的效率比B树更高，因为叶子节点通过链表相连。

## 知识扩展
### B+树的优缺点
优点：
1. 减少磁盘I/O操作次数，提高查询效率
2. 所有数据都在叶子节点，查询路径长度一致，查询稳定性好
3. 叶子节点通过链表相连，支持高效的范围查询和顺序访问
4. 内部节点不存储数据，可以容纳更多键值，降低树的高度
5. 适合数据库索引等需要大量范围查询的场景

缺点：
1. 实现复杂度高
2. 相比B树，需要遍历到叶子节点才能获取数据
3. 插入和删除操作可能导致大量节点更新
4. 不适合单点查询频繁的场景

### B+树在数据库中的应用
1. 索引结构：
   - 大多数关系型数据库（如MySQL、Oracle、PostgreSQL）使用B+树作为索引结构
   - 内部节点存储索引键值，叶子节点存储数据记录或指向数据记录的指针

2. 聚集索引与非聚集索引：
   - 聚集索引：叶子节点直接存储数据记录
   - 非聚集索引：叶子节点存储指向数据记录的指针

3. 多级索引：
   - 数据库可以建立多级B+树索引，提高复杂查询的效率

4. 事务处理：
   - B+树结构便于实现MVCC（多版本并发控制）等事务处理机制

### B+树与其他数据结构的比较
1. 与哈希表比较：
   - B+树支持范围查询和顺序访问，哈希表不支持
   - 哈希表的单点查询通常比B+树更快（O(1) vs O(log n)）
   - B+树维护数据的有序性，哈希表不维护

2. 与红黑树比较：
   - B+树更适合磁盘存储，红黑树更适合内存存储
   - B+树的高度通常比红黑树小，I/O操作更少
   - 红黑树实现相对简单，但在外存环境下效率较低

3. 与LSM树比较：
   - B+树适合读操作频繁的场景，LSM树适合写操作频繁的场景
   - LSM树写入性能更好，但读取性能可能较差
   - B+树结构相对稳定，LSM树需要定期合并

## 功能实现
以 Java 为例，实现B+树的基本操作。
```java
public class BPlusTree<K extends Comparable<K>, V> {
    private static final int DEFAULT_ORDER = 4; // 默认为4阶B+树
    
    private Node root;
    private final int order; // B+树的阶数
    private int size;
    private LeafNode firstLeaf; // 指向第一个叶子节点，用于顺序遍历
    
    // B+树节点抽象类
    private abstract class Node {
        protected int keyCount; // 当前节点中键值的数量
        protected K[] keys; // 键值数组
        
        // 节点构造函数
        @SuppressWarnings("unchecked")
        public Node() {
            this.keys = (K[]) new Comparable[order - 1]; // 最多存储order-1个键值
            this.keyCount = 0;
        }
        
        // 判断节点是否为叶子节点
        public abstract boolean isLeafNode();
    }
    
    // 内部节点类
    private class InternalNode extends Node {
        protected Node[] children; // 子节点数组
        
        // 内部节点构造函数
        @SuppressWarnings("unchecked")
        public InternalNode() {
            super();
            this.children = new Node[order]; // 最多有order个子节点
        }
        
        @Override
        public boolean isLeafNode() {
            return false;
        }
    }
    
    // 叶子节点类
    private class LeafNode extends Node {
        protected V[] values; // 值数组
        protected LeafNode next; // 指向下一个叶子节点的指针
        
        // 叶子节点构造函数
        @SuppressWarnings("unchecked")
        public LeafNode() {
            super();
            this.values = (V[]) new Object[order - 1]; // 最多存储order-1个值
            this.next = null;
        }
        
        @Override
        public boolean isLeafNode() {
            return true;
        }
    }
    
    // 构造函数
    public BPlusTree() {
        this(DEFAULT_ORDER);
    }
    
    public BPlusTree(int order) {
        if (order < 3) {
            throw new IllegalArgumentException("B+树的阶数必须大于等于3");
        }
        this.order = order;
        this.root = new LeafNode(); // 初始化根节点为叶子节点
        this.firstLeaf = (LeafNode) root;
        this.size = 0;
    }
    
    // 查找操作
    public V search(K key) {
        if (key == null) {
            throw new IllegalArgumentException("键不能为空");
        }
        return search(root, key);
    }
    
    private V search(Node node, K key) {
        if (node.isLeafNode()) {
            LeafNode leaf = (LeafNode) node;
            int i = 0;
            while (i < leaf.keyCount && key.compareTo(leaf.keys[i]) > 0) {
                i++;
            }
            if (i < leaf.keyCount && key.compareTo(leaf.keys[i]) == 0) {
                return leaf.values[i];
            }
            return null;
        } else {
            InternalNode internal = (InternalNode) node;
            int i = 0;
            while (i < internal.keyCount && key.compareTo(internal.keys[i]) >= 0) {
                i++;
            }
            return search(internal.children[i], key);
        }
    }
    
    // 插入操作
    public void insert(K key, V value) {
        if (key == null) {
            throw new IllegalArgumentException("键不能为空");
        }
        
        // 如果根节点已满，需要分裂
        if (root.keyCount == order - 1) {
            InternalNode newRoot = new InternalNode();
            newRoot.children[0] = root;
            splitChild(newRoot, 0);
            root = newRoot;
        }
        
        insertNonFull(root, key, value);
        size++;
    }
    
    // 在非满节点中插入键值对
    private void insertNonFull(Node node, K key, V value) {
        if (node.isLeafNode()) {
            LeafNode leaf = (LeafNode) node;
            int i = leaf.keyCount - 1;
            
            // 找到合适的插入位置
            while (i >= 0 && key.compareTo(leaf.keys[i]) < 0) {
                leaf.keys[i + 1] = leaf.keys[i];
                leaf.values[i + 1] = leaf.values[i];
                i--;
            }
            
            // 插入新键值对
            leaf.keys[i + 1] = key;
            leaf.values[i + 1] = value;
            leaf.keyCount++;
        } else {
            InternalNode internal = (InternalNode) node;
            int i = internal.keyCount - 1;
            
            // 找到合适的子节点
            while (i >= 0 && key.compareTo(internal.keys[i]) < 0) {
                i--;
            }
            i++;
            
            // 如果子节点已满，需要先分裂
            if (internal.children[i].keyCount == order - 1) {
                splitChild(internal, i);
                if (key.compareTo(internal.keys[i]) > 0) {
                    i++;
                }
            }
            
            // 递归在子节点中插入
            insertNonFull(internal.children[i], key, value);
        }
    }
    
    // 分裂子节点
    private void splitChild(InternalNode parent, int index) {
        Node child = parent.children[index];
        
        if (child.isLeafNode()) {
            LeafNode leafChild = (LeafNode) child;
            LeafNode newLeaf = new LeafNode();
            
            // 分配键值对
            int mid = order / 2;
            for (int j = mid; j < leafChild.keyCount; j++) {
                newLeaf.keys[j - mid] = leafChild.keys[j];
                newLeaf.values[j - mid] = leafChild.values[j];
                newLeaf.keyCount++;
            }
            
            // 更新原叶子节点的键值对数量
            leafChild.keyCount = mid;
            
            // 更新叶子节点链表
            newLeaf.next = leafChild.next;
            leafChild.next = newLeaf;
            
            // 在父节点中插入分隔键
            for (int j = parent.keyCount; j > index; j--) {
                parent.children[j + 1] = parent.children[j];
                parent.keys[j] = parent.keys[j - 1];
            }
            parent.children[index + 1] = newLeaf;
            parent.keys[index] = newLeaf.keys[0]; // 使用新叶子节点的第一个键作为分隔键
            parent.keyCount++;
        } else {
            InternalNode internalChild = (InternalNode) child;
            InternalNode newInternal = new InternalNode();
            
            // 分配键值和子节点
            int mid = (order - 1) / 2;
            K midKey = internalChild.keys[mid];
            
            // 复制右半部分到新节点
            for (int j = mid + 1; j < internalChild.keyCount; j++) {
                newInternal.keys[j - (mid + 1)] = internalChild.keys[j];
                newInternal.keyCount++;
            }
            
            for (int j = mid + 1; j <= internalChild.keyCount; j++) {
                newInternal.children[j - (mid + 1)] = internalChild.children[j];
            }
            
            // 更新原内部节点的键值对数量
            internalChild.keyCount = mid;
            
            // 在父节点中插入分隔键
            for (int j = parent.keyCount; j > index; j--) {
                parent.children[j + 1] = parent.children[j];
                parent.keys[j] = parent.keys[j - 1];
            }
            parent.children[index + 1] = newInternal;
            parent.keys[index] = midKey;
            parent.keyCount++;
        }
    }
    
    // 范围查询操作
    public List<V> rangeSearch(K startKey, K endKey) {
        if (startKey == null || endKey == null) {
            throw new IllegalArgumentException("键不能为空");
        }
        if (startKey.compareTo(endKey) > 0) {
            throw new IllegalArgumentException("起始键必须小于等于结束键");
        }
        
        List<V> result = new ArrayList<>();
        LeafNode leaf = findLeafNode(root, startKey);
        
        // 遍历叶子节点链表，收集范围内的值
        while (leaf != null) {
            for (int i = 0; i < leaf.keyCount; i++) {
                if (leaf.keys[i].compareTo(startKey) >= 0 && leaf.keys[i].compareTo(endKey) <= 0) {
                    result.add(leaf.values[i]);
                }
                if (leaf.keys[i].compareTo(endKey) > 0) {
                    return result;
                }
            }
            leaf = leaf.next;
        }
        
        return result;
    }
    
    // 查找包含指定键的叶子节点
    private LeafNode findLeafNode(Node node, K key) {
        if (node.isLeafNode()) {
            return (LeafNode) node;
        } else {
            InternalNode internal = (InternalNode) node;
            int i = 0;
            while (i < internal.keyCount && key.compareTo(internal.keys[i]) >= 0) {
                i++;
            }
            return findLeafNode(internal.children[i], key);
        }
    }
    
    // 获取B+树大小
    public int size() {
        return size;
    }
    
    // 判断B+树是否为空
    public boolean isEmpty() {
        return size == 0;
    }
    
    // 顺序遍历所有值
    public List<V> values() {
        List<V> result = new ArrayList<>();
        LeafNode leaf = firstLeaf;
        
        while (leaf != null) {
            for (int i = 0; i < leaf.keyCount; i++) {
                result.add(leaf.values[i]);
            }
            leaf = leaf.next;
        }
        
        return result;
    }
}
```
